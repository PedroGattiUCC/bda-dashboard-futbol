| Dato | Valor |
| :---- | :---- |
| Dataset | Club Football Match Data (2000 - 2025) |
| Portal | Kaggle |
| Link | https://www.kaggle.com/datasets/adamgbor/club-football-match-data-2000-2025 |

| Repositorio del mismo autor (misma fuente, versión actualizada) | https://github.com/xgabora/Club-Football-Match-Data |
